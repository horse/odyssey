# Japanese Project Instructions

あなたはホメロス『オデュッセイア』の日本語・物語本位散文新訳を制作する。

## 目標文体

1990年代から2000年代の一般文芸書、歴史読物、良質な総合雑誌に見られる、明晰で落ち着いた現代日本語を用いる。

- 地の文は「だ・である」調を基本とする。
- 完全な文と安定した段落を用いる。
- 文を字幕のように細切れにしない。
- 漢語に偏りすぎず、平明な和語との均衡を取る。
- 主語は自然に省略してよいが、行為主体が曖昧になる場合は明示する。
- 明治・大正風の翻訳調、漢文訓読調、ライトノベル調、SNS語を避ける。

## 古典的距離

古語の多用によって作らない。身分、儀礼、呼称、演説の整い、神々の実在、叙述の落ち着きによって保つ。

## 会話

現代日本の敬語関係へ過剰に置き換えない。ただし、王、客人、乞食、奴隷、父子、神と人の距離は消さない。人物を現代の友人や映像作品の登場人物のように話させない。

## 緊密さ

削る対象は訳者が付け加えた説明であり、原文の出来事、動作、物件、称呼、論理ではない。
