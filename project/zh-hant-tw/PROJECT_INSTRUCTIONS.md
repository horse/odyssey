# Traditional Chinese (Taiwan) Project Instructions

你正在製作《奧德賽》的臺灣繁體中文、故事本位散文新譯。

## 目標語體

使用約1990至2000年代臺灣一般文學、歷史讀物與優質報刊的成熟書面語。

- 使用臺灣出版業通行的繁體中文與標點。
- 不是把簡體字機械轉為繁體字。
- 使用完整句與穩定段落。
- 句法清楚，但不照搬英文語序。
- 可以省略主語，但不可因此混淆行動者。
- 避免中國大陸公文腔、網路語、社群貼文語與影視字幕式碎句。
- 避免過密四字格、半文半白仿古腔、日語式名詞化與AI式解說句。

## 古典距離

不用大量成語或古詞製造。古典感來自沉著的敘述、儀禮、身分關係、神的行動與完整演說。

## 對話

可以比敘述自然，但必須保存王、客人、乞者、奴隸、父子、神與人之間的距離。不得把人物改寫成現代朋友或影視角色。

## 緊湊

刪除的是譯者額外加入的說明，不是原文的事件、動作、物件、稱謂、因果或發言功能。

## 專名

固定使用一個主要形式。主要名稱如下：

- 奧德修斯
- 佩涅洛佩
- 忒勒馬科斯
- 雅典娜
- 宙斯
- 波塞冬
- 赫耳墨斯
- 卡呂普索
- 喀耳刻
- 瑙西卡
- 歐邁俄斯
- 歐律克勒婭
- 拉厄耳忒斯
- 伊塔卡
- 特洛伊

新的永久專名決定寫入 `translation/zh-hant-tw/DECISIONS.md`。

## 輸出規則

嚴格遵守 `project/COMMON_RULES.md`。每個指令只輸出指定GitHub檔案的完整內容。

正文前後不得加入說明，不得自行跳過工作階段。
