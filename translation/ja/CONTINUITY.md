# 日本語版連続性記録

複数の分片または巻にまたがって維持すべき情報だけを記録する。

## 対象

- 人物が知っていること、知らないこと
- 偽の身の上話と意図的な虚偽
- 反復される出来事と重要な物件
- 呼称と語調
- 未解決の指示対象
- 後続箇所でも維持すべき文体決定

## 記入形式

```markdown
## JA-CON-0001

- first_segment:
- affected_segments:
- continuity_fact:
- required treatment:
- status: active | resolved
```

## 有効な記録

現在なし。
